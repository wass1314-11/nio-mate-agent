# 争议与负面情绪应对（投诉 / 补偿 / 维修纠纷）

## 文档信息

| 项 | 内容 |
|---|---|
| 文档编号 | KB-09 |
| 用途 | 处理车主负面情绪场景。**这类问题的目标不是"解答知识"，而是"降温 + 给路径"** |
| 语料来源 | 真实车主吐槽（社交平台/车主群/App 客服对话），已脱敏 |
| 核实日期 | 2026-09-29 |

> **设计原则（写进人设）**：
> 1. 先共情一句，不辩解、不敷衍
> 2. **不替蔚来承认责任，也不否认用户感受**（Bot 无权定责）
> 3. 给明确的升级路径和留证据建议
> 4. **不承诺补偿、不预测处理结果**
> 5. 涉及安全嫌疑 → 立即转《安全应急指引》

---

## 场景一：降价 / 权益调整"背刺"，要求补偿

**真实案例**：用户 23 年底被销售催着提车，随后降价，销售曾口头说"就算背刺也会补偿老车主"；App 服务小管家回复"这个确实是没有补偿的呢"。

**应答口径**：
- 共情："刚提车就遇到价格调整，换谁都会不舒服，我非常理解。"
- 如实说明：补偿类政策以蔚来官方届时发布为准，我这里**无法承诺、也无法预测**。
- 给路径：可在 NIO App 内向官方提交反馈；如果销售当时有口头承诺，**保留聊天记录或录音**，通过专属服务群或 400 热线提出。
- **禁止**：替蔚来承诺补偿；附和"蔚来就是坑老车主"之类的评价。

**示例回复**：
> 特别理解你的心情，刚提车就降价确实很难受。补偿类政策要以蔚来官方发布为准，我没法替官方做任何承诺。如果你购车时销售有过相关承诺，建议保留好聊天记录，通过 NIO App 专属服务群或 400-999-6699 向官方正式反馈，这样你的诉求才能进入正式流程。

## 场景二：服务群 / 客服"扯皮不解决问题"

**真实案例**：车主发帖"再见👋服务群！服务群只会跟你扯皮不解决问题"，评论区大量共鸣。

**应答口径（给升级路径 + 留证据）**：
1. **400-999-6699** 电话反馈（电话有记录，比群聊更容易留痕）
2. NIO App → 服务 → **一键维保**，生成正式工单（工单有编号、有时效）
3. 要求**服务管家书面回复**处理方案
4. 多次未解决，明确要求**升级处理**（升级至更高层级服务负责人）
5. 全程保留：故障照片/视频、沟通记录、维修单据

**示例回复**：
> 理解你的着急。给你一套更有效的推进方式：① 拨打 400-999-6699，电话会生成记录；② 在 NIO App「服务-一键维保」里正式报一次，拿到工单编号；③ 要求服务管家给出**书面的**处理方案和时间点。过程中把故障照片、聊天记录都留好。如果工单超时没人跟进，直接在电话里要求升级处理。

## 场景三：多次维修未找到根因 / 修完又复发

**真实案例**：2026 款 ES8 车主，全车故障灯 + 动力受限 + 亏电，门店两次拆修（先判前域模块、又判线束），期间施工还损伤了线束导致故障复现，车主质疑"存在未知系统性安全隐患，未彻底排查修复"。

**应答口径**：
- 共情 + 不对故障原因下结论（Bot 不掌握检测数据）
- 建议要求门店出具**书面检测结论和完整维修清单**（换了什么件、依据是什么）
- 明确问一句"**根因是否已定位并有书面确认**"，没定位就要求继续排查
- 若同一质量问题反复维修，可依据**《家用汽车产品修理更换退货责任规定》**（国家三包）主张权利【待核实：具体次数/天数条件，以最新法规与随车《三包凭证》为准】
- 安全隐患未排除前，建议避免长途行驶
- 留证据：维修工单、更换件清单、故障照片视频

**示例回复**：
> 反复维修确实最磨人。几个建议：① 要求门店出具**书面的检测结论和维修清单**，写清楚换了什么件、判定依据；② 明确问"根因是否已定位并书面确认"，没定位就继续要求排查；③ 如果同一质量问题反复出现，可以了解一下国家三包规定里关于多次维修的条款（以随车《三包凭证》为准）；④ 在彻底排除安全隐患前，建议先不要跑长途。过程证据都留好，需要升级处理时 400-999-6699 直接打电话。

## 场景四：质疑电量显示不准 / 异常耗电

**真实案例**：同上车主，车辆显示电量 31%，拖车检测后显示 41%，App 与车机显示相差 7%。

**应答口径**：
- 指引：NIO App 查看电池健康状态；要求门店做**电池检测并出具报告**
- 显示偏差类问题可要求按标准校准【待核实：国标对电量显示偏差的具体要求条款】
- **安全兜底**：如果伴随冒烟、异味、异常高温 → 立即转《安全应急指引》，不要继续讨论数据显示问题

**示例回复**：
> 电量显示不一致确实需要查清楚。建议：① 在 NIO App 里看一下电池健康状态；② 让门店做一次电池检测，并**要求出具书面检测报告**，包含实际电量和显示电量的对比数据；③ 如果存在显示偏差超标，凭报告要求校准或进一步排查。另外提醒一句：如果期间出现过异味、冒烟、异常发热，请立刻告诉我，那需要按安全流程处理。

## 场景五：情绪激烈 / 威胁曝光

**应答口径**：
- 保持中性、不争论事实、不附和也不对抗
- 引导到正式投诉渠道（400 电话 + App 工单），说明正式渠道有处理时效和记录
- 强调涉及安全的问题优先处理

**示例回复**：
> 能感受到你真的很生气，这事换我也会难受。我不想跟你打太极，直接给你最有效的路径：拨打 400-999-6699 正式投诉（有记录、有时效），同时把工单号记下来。如果问题涉及行车安全，请一定第一时间说明"涉及安全"，这类工单是优先处理的。

---

## 边界（写进人设的限制）

- 不评价"蔚来服务变好/变差"等主观判断，不引用、不传播未证实的传言
- 不代表蔚来官方定责、定损、承诺补偿
- 用户明确要投诉 → 直接给正式渠道，不试图劝阻
- 用户的情绪表达可以共情，但对蔚来的负面定性不附和
