## 一、四项基本权益（告知书正文原文口径）

### 1. 车联网服务

- **基础流量服务**（实时路况导航 + FOTA/SOTA 升级）：**终身免费、不限数据流量**
- **免费娱乐流量**：自交付之日起 **6 年内**（且在车辆使用寿命周期内）中国境内**每月最多 8GB**，由蔚来合作伙伴或基础电信运营商提供

### 2. 首任车主质保服务（整车）

- 自交付之日起 **6 年或行驶里程 15 万公里**（以先到者为准）
- 准确表述：在《保修手册》规定之**整车包修期（36 个月或 12 万公里）届满后的剩余使用寿命周期**内继续提供的延长质保
- **BaaS（动力电池租用及服务方案）用户**：本条款不适用于动力电池，但蔚来或其合作伙伴会采取措施保障动力电池健康可用

### 3. 三电系统 10 年质保

- 自交付之日起 **10 年，不受行驶里程限制**
- 准确表述：在《保修手册》规定之**关键零部件包修期（96 个月或 12 万公里）届满后的剩余使用寿命周期**内继续提供
- 三电系统 = 关键零部件 = **动力电池及管理系统、驱动电机及其控制器、整车控制器**（以《保修手册》规定为准）
- **BaaS 用户**：同上，不适用于动力电池

### 4. 终身道路救援

- 触发条件：**蔚来汽车发生故障而无法行驶**
- 范围：车辆使用寿命周期内、中国境内
- 细则见本文第五节

## 二、关键定义（回答质保问题时会用到）

| 术语 | 告知书定义 |
|---|---|
| **质量问题** | 产品设计、制造或原材料缺陷 |
| **三电系统** | 关键零部件（动力电池及管理系统、驱动电机及其控制器、整车控制器），以《保修手册》为准 |
| **整车零部件** | 关键零部件、易损耗零部件**之外**的整车原车零部件 |
| **易损耗零部件** | 不在首任车主质保范围内，种类及质保以《保修手册》为准 |
| 索赔材料 | 蔚来可要求提供**购车发票、行驶证**等有效文件；拒绝或无法提供时蔚来有权暂不提供服务 |
| 换件归属 | 质保维修中被更换下的零部件**归蔚来公司所有** |

## 三、首任车主质保的终止情形

1. **所有权变更（过户）**：完成机动车所有权变更登记的**当日**终止
2. **事故伤及底盘主要部件或整车主要总成**，且经蔚来公司合理判断须更换的 → 自判断之日起终止
3. **车辆批准报废，或被保险公司查勘定损为全损**
4. 法律法规或实施细则规定的其他情形

> 总开关：**转让、报废、全损**任一发生 → 全部基本权益终止且**不可恢复**。

## 四、首任车主质保的除外情形（不予质保）

| 类别 | 具体情形 |
|---|---|
| 自然损耗 | 正常老化造成的变质、变形、褪色；正常磨损、损耗 |
| 用途违规 | 出租/营运、比赛竞技、表演娱乐、试验、军事行动、征用等 |
| 改装 | 未经蔚来合法有效授权，擅自改装、调整、拆卸造成损坏 |
| 处置不当 | 故障后被不当处置，或未按要求/未按《用户手册》停止使用造成扩大损坏 |
| 使用不当 | 未按《用户手册》《保修手册》正确使用、维护、修理造成损坏 |
| 不可抗力 | 冰雹、碎石、鸟粪、工业粉尘、洪水、暴风、雷电、地震、海水、酸雨、腐蚀性物质等 |
| 人为因素 | 车主、使用人或第三方的不适当或犯罪行为（故意破坏、非法闯入、盗抢等） |
| 非官方维修 | 由未获授权的个人/实体维修及其导致的损坏，含使用非蔚来纯正零部件 |
| 特殊用途 | 将车辆**用作固定电源**导致的损坏 |
| 化学处理 | 化学品或密封胶错误使用导致损坏 |
| 外因事故 | 非质量问题导致的事故、**超载、涉水、外部火灾和爆炸** |

> 两条高频误解，回答时要说清边界、不要吓唬用户：
> ① "**自己找修理厂保养**"对应"非官方渠道维修"条款——**不是**在外面保养一次就全车脱保，而是**该次非授权维修及其导致的损坏**不在质保范围。
> ② "**改装**"只免除**改装造成的损坏**对应的质保，同样不是一刀切。

## 五、终身道路救援实施细则（附件B 原文口径）

### 服务范围
车辆**发生故障而无法行驶**时，在车辆使用寿命周期内、中国境内提供救援。
> ⚠️ 边界：救援针对"**故障**"。**交通事故**导致无法行驶属于出险理赔流程（走保险），两者通道不同，回答时要分清。

### 五种服务方式（由蔚来根据故障情况决定一种或多种）
1. **远程救援**：远程手段诊断、排除故障
2. **现场诊断**：安排移动服务车及道路服务专员赶赴现场
3. **拖车救援**：拖送至蔚来指定的充换电站或服务中心
4. **困境救援**：专业设备（如大型吊车）牵引至可拖运状态后拖送
5. **特殊路段救援**：由蔚来直接或协助车主联系当地交警/政府指定拖车实体

### 费用承担
- 蔚来承担其自行产生的上述五类救援费用
- **特殊路段救援**：若车主已向第三方救援实体**垫付经蔚来事先确认**的拖车费，蔚来**凭发票**返还费用或等值蔚来积分，上限为**当地政府规定的拖车服务指导价**
- ⚠️ **未经蔚来事先认可**自行联系第三方救援产生的费用由车主自行承担——要主动提醒用户"先联系蔚来，别自己叫拖车"

### 救援除外情形
- 车辆用于营运/竞技/试验等特殊用途
- 驾驶人存在**酒驾、毒驾**等违法行为或参与违法犯罪
- 不可抗力导致无法提供救援（自然灾害、战争、暴乱、罢工等），事件消除后继续提供服务
