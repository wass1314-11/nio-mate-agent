## 排查通用三步

1. **确认现象**：什么时候开始的？一直存在还是偶发？有没有故障提示？
2. **先试软重启**：多数车机类问题可通过重启解决。
3. **仍无法解决**：NIO App → 服务 → 一键维保，或联系专属服务群 / 400-999-6699。

> 追问要点：涉及车机问题时，需先问清**车型**（不同车机的重启方式不同）。

## 一、车机与网络

### Q1：车机突然连不上网怎么办？

**结论**：先重启车机，多数可恢复。

**排查顺序**：
1. **重启车机**：按车型对应方式重启 **【待核实：不同车型的按键组合，例如长按方向盘两侧按键约 10 秒】**
2. 观察车内 4G/5G 信号图标，确认是"无信号"还是"有信号但用不了"
3. 如果车辆停在地下车库、隧道、偏远区域，属于正常的信号盲区，驶出后会自动恢复
4. 重启后仍无网络：在 NIO App 内联系在线客服或专属服务群，由后台远程诊断

**说明**：车联网基础流量服务为终身免费、不限数据流量 **【待核实：娱乐流量的额度与有效期】**。如果是"网络正常但某个 App 用不了"，多为此类服务侧问题。

### Q2：车机卡顿、黑屏、死机怎么办？

**结论**：先强制重启车机，再考虑到店检测。

**排查顺序**：
1. 强制重启车机（方式同 Q1）
2. 检查是否有待安装的系统更新（FOTA），部分问题在新版本已修复
3. 重启后频繁黑屏/死机 → NIO App 一键维保，到店检测车机硬件

### Q3：导航定位不准、地图不更新怎么办？

**结论**：先重启车机并确认网络正常，若持续异常到店检测。

**排查顺序**：
1. 确认车机已联网（参考 Q1）
2. 重启车机
3. 检查是否有地图/系统更新待安装
4. 仍异常 → 一键维保

## 二、启动与钥匙

### Q4：车辆无法启动怎么办？

**结论**：按顺序排查，多数是钥匙/手机钥匙与操作步骤问题。

**排查顺序**：
1. 确认钥匙或手机在车内（手机钥匙需确认蓝牙已开、App 已登录）
2. 踩住刹车，再挂挡
3. 检查仪表是否有低压蓄电池亏电提示
4. 若完全无反应且伴随仪表全黑 → 可能为 12V 蓄电池亏电，联系 400-999-6699 或 App 一键维保

### Q5：手机蓝牙钥匙连不上车怎么办？

**结论**：多为手机侧权限或蓝牙问题，按顺序排查。

**排查顺序**：
1. 确认手机蓝牙已开启，且已关闭与其它车辆的旧连接
2. 确认 NIO App 在后台有定位与蓝牙权限（权限被省电策略限制是常见原因）
3. 重启 App 或重新登录
4. 用实体钥匙应急解锁
5. 仍无法解决 → App 内联系在线客服重绑

### Q6：解锁后车辆报警器一直响？

**结论**：用钥匙重新解锁或启动车辆即可解除；频繁误报需到店检测。

## 三、空调与车内环境

### Q7：空调有异味怎么办？

**结论**：多为空调滤芯长期未更换，建议更换空调滤芯。

**说明**：更换周期 **【待核实：1 年 1 次 / 随保养周期】**。若更换后仍有异味，建议到店做空调系统清洁。

**操作**：NIO App → 服务 → 预约保养/维修 → 项目选择空调滤芯更换。

### Q8：空调不制冷/制热效果差怎么办？

**结论**：先确认是设置问题，再考虑到店检测。

**排查顺序**：
1. 确认温度设定与 A/C 开关状态、是否误开"仅通风"
2. 确认是否处于「节能模式」或电量极低导致空调功率受限
3. 出风量明显变小 → 可能是空调滤芯堵塞，更换滤芯
4. 仍不制冷 → 一键维保，到店检测冷媒与压缩机

## 四、轮胎与胎压

### Q9：胎压报警了怎么办？

**结论**：先在 NIO App 查看实时胎压，明显偏低时补气；补不上的多为扎胎。

**排查顺序**：
1. **标准胎压值以主驾侧车门 B 柱标签标注值为准**（各车型/轮胎规格不同，**不要套用统一数值**）
2. NIO App → 爱车 → 实时查看四轮胎压，定位是哪个轮子异常
3. 明显低于标准值 → 就近充气；如持续掉压，判断为扎钉/破损
4. **扎胎不用自己换胎**：蔚来提供 7×24 小时上门补胎服务，在 NIO App 内一键呼叫，移动技师上门处理
5. 若车辆因此无法行驶且不具备行驶条件，可申请道路救援（见《售后理赔与道路救援》）

### Q10：轮胎被扎了，需要自己换备胎吗？

**结论**：不需要。呼叫上门补胎即可。

**操作**：NIO App → 服务 → 上门补胎（移动服务），7×24 小时响应。

### Q11：轮胎多久需要更换？

**结论**：视磨损情况而定，主要看花纹深度与老化程度，一般 4-6 万公里或出现明显老化裂纹时评估更换 **【待核实】**。

**说明**：轮胎属于易损耗件，**不在整车质保范围内**。

## 五、故障灯与电量显示

### Q12：全车故障灯亮红色报警、提示动力系统受限怎么办？

**结论**：先按安全流程停靠，再走正式报修流程，并留证据。

**操作步骤**：
1. 若行驶中 → 安全靠边停车、下电（参考《安全应急指引》）
2. **拍照/录像**留存故障灯与提示信息，发送到专属服务群
3. 联系蔚来 400-999-6699，按指导操作（如设置拖车模式）
4. 配合拖车检测，**要求门店出具书面检测结论**
5. 若门店无法定位故障原因，要求**上报总部技术支持**；多次维修未解决的，参考《争议与负面情绪应对》场景三

### Q13：App 和车机电量显示不一致 / 掉电异常快怎么办？

**结论**：要求门店做电池检测并出具书面报告，凭数据判断是否异常。

**操作步骤**：
1. 记录异常表现：时间、显示数值、环境温度、是否刚换电/充电
2. NIO App 查看电池健康状态
3. 预约检测，要求出具**含实际电量与显示电量对比的书面报告**
4. 显示偏差明显超标时，凭报告要求校准或进一步排查【待核实：电量显示偏差的现行标准条款】

**安全兜底**：若伴随异味、冒烟、异常发热 → 立即按《安全应急指引》处理，停止讨论数据显示问题。

## 六、充电相关故障

### Q14：家充桩充不上电怎么办？

**结论**：按顺序排查，多数是桩端或通信问题。

**排查顺序**：
1. 确认车辆已插枪到位、车机显示"已连接"
2. 确认家充桩指示灯状态（是否有故障灯）
3. 在 NIO App 内查看充电订单是否正常发起
4. 尝试断开重插，或对桩做一次重启
5. 仍无法充电 → NIO App 内报修家充桩，官方安排上门检测

### Q15：公共桩扫描后无法启动充电？

**结论**：先确认桩的状态与账户，再考虑换桩。

**排查顺序**：
1. 确认该桩在 App 内显示"可用"而非"故障/占用"
2. 确认 App 内余额或支付方式正常
3. 尝试更换相邻枪位或换站
4. 多次失败 → App 内反馈该桩故障
