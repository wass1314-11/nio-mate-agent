# 经典版扣子迁移清单（空间版 Agent → Bot 开发页面）

> 背景结论：扣子空间版 Agent 的联网搜索是平台层强制工具，人设拦不住（实测：人设写明"没有任何联网搜索能力"仍引用"北京发布"报天气）。
> 经典版 Bot 编辑器默认不联网、知识库/人设/工作流全部可配，且作品集需要的工作流只有经典版有。

---

## 迁移步骤（约 15 分钟）

### 1. 进入经典版
- 打开 www.coze.cn → 工作空间 → **项目开发 → 创建 Bot**
- ⚠️ 不是"扣子空间/智能体"入口，是「项目开发/Bot 开发」页面

### 2. 基础配置
| 项 | 填写 |
|---|---|
| Bot 名称 | 蔚来小助手 NIO Mate |
| 简介 | 你的蔚来用车管家，7×24 小时解答用车、保养、充电、售后问题 |
| 模型 | 豆包 1.5 Pro 或 DeepSeek-V3，温度 **0.3** |
| 开场白 | 用 `_配置_高频引导问题与开场按钮.md` 第四节的文案 |
| 引导问题 | 该文件第一节的 6 个按钮 |

### 3. 人设与回复逻辑
- 粘贴 `_配置_人设与回复逻辑_最终版.md` 代码框全文（已是联网免疫版措辞）
- 经典版默认**不联网**，人不加搜索插件就不会搜——这里是真正的关联网

### 4. 知识库
- 「知识库」→ 新建 → 文本格式 → 上传 01-09 共 9 份 md（**不含** 00/测试集/_源文件/_配置）
- 分段设置：按标题分段或 500 字自动分段
- 召回设置：**top_k = 3**，混合检索（语义+关键词）打开
- Bot 里挂上该知识库，提示词选"使用知识库内容回答"

### 5. 工作流（作品集核心，加分级项）
按原始方案搭意图识别工作流：
```
开始 → 大模型节点（意图识别：保养/充电/故障/理赔/负面情绪/超纲）
├─ 保养/充电/理赔 → 知识库检索 → 输出
├─ 故障 → 条件分支（安全风险？）→ 是：04 紧急指引 / 否：知识库检索
├─ 负面情绪 → 09 文档口径输出
└─ 超纲 → 输出固定话术「超出我的范围了，我会努力学习的」
```
意图识别节点提示词：`判断用户问题属于哪一类：保养/充电/故障/理赔/负面情绪/超纲，只输出类别名`

### 6. 验证（发布前跑 5 条）
| 输入 | 期望 |
|---|---|
| 首保什么时候做？ | 知识库口径，无网页引用 |
| 今天天气怎么样 | 只回固定话术 |
| 你喜欢可乐还是百事 | 只回固定话术 |
| 车冒烟了 | 紧急指引 + 400-999-6699（不能兜底） |
| 最新购车优惠有哪些 | 只回固定话术 |

### 7. 发布
- 发布渠道按需选（网页 SDK / 微信客服等）
- 发布后用测试集_31条.csv 正式跑分，填"实际回答/是否通过/误答归因"三列
