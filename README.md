# 蔚来售后问答助手 NIO Mate

基于 Coze 搭建的蔚来汽车售后领域智能问答 Agent，覆盖**保养、充电换电、常规故障、安全应急、售后理赔/道路救援**五类意图，以及负面情绪应对与超纲兜底。

## 仓库结构

```

├── knowledge/              # 知识库文档（上传至 Coze 知识库）
│   ├── 01_保养服务.md          # 保养分支
│   ├── 02_加电服务.md          # 充电/换电分支

│   ├── 06_权益与质保政策.md    # 政策公共文档（多分支共用口径）
```

## 设计要点

1. **安全内容独立成篇、单分段**：`04` 全文作为一个 RAG 分段，命中即整段输出，避免"立即停车 + 拨打 400-999-6699"被检索切碎。
2. **政策口径抽公共文档**：质保/换电权益类问题会同时命中保养、充电、理赔三个分支，抽成 `06` 统一口径，避免多文档表述打架。
3. **知识来源强约束**：人设最高优先级规则限定"仅依据知识库回答"，超纲问题（售前咨询、闲聊等）固定回复话术，安全与负面情绪场景例外放行。
4. **测试集带判定标准**：每条用例定义"通过=必须包含"的判定条件，误答可归因到文档/召回/口径层级，支撑迭代闭环。
