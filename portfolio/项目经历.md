## 面试追问预案

1. **"测试结果怎么样？"**
   照实讲首轮结果：31 条测试集首轮暴露 3 类问题（联网搜索污染口径、超纲兜底失效、负面场景编造权益承诺），全部归因到根因——平台内置联网不受提示词管控 → 做出平台选型迭代。这个"识别问题→定位根因→选型迭代"的闭环比一个漂亮的通过率更值钱。
2. **"为什么换平台？"**
   空间版 Agent 的联网是编排层强制工具，人设（系统提示词）无法约束工具调用；知识问答对口径确定性要求高，故迁移经典版获得召回参数与工作流控制力。
3. **"知识库为什么这么切？"**
   两个设计决定：安全应急单独成篇且单分段（防"立即停车+400"被 RAG 切碎）；质保/权益抽成公共文档（同政策命中多分支时口径不打架）。
4. **"数据哪来的？"**
   官方：nio.cn 服务承诺页 + 《车主基本权益告知书》全文；真实语料：车主群吐槽、蔚来 App 热榜 TOP5——分别解决"口径权威性"和"真实 query 分布"。
